# 露西 -她所期望的一切- 无障碍补丁

面向视障玩家的非官方无障碍补丁：让《露西 -她所期望的一切-》中文版能用读屏软件
（NVDA / 争渡 / Windows 自带 SAPI）朗读剧情、选项和菜单，并且全程只用键盘就能玩。

- 当前版本：**0.2.0.0**（开发中，尚未发布）
- 支持游戏：中文版 Ver 1.14（引擎 nkNovel 1.50，32 位）
- 支持系统：Windows 10 / 11（32 位游戏）
- 项目性质：非官方、免费、开源（MIT），与游戏开发商、发行商无关

> 状态说明：仓库刚建立骨架，大量内容**还没有实机验证**。本文中凡是写
> “待实测 / 待定稿”的地方，都代表我们还没测过，请不要当成已经可用的承诺。
> 实测完成后会逐条更新。

## 这是什么

原版游戏画面上的文字，读屏软件读不到，也没法用键盘把每个按钮走一遍。
这个补丁是一个 32 位原生 DLL，通过替换游戏目录里的 `d3dx9_40.dll` 进入游戏进程，
把剧情文字、选项、菜单项交给读屏软件朗读，并让游戏原生的键盘操作对读屏友好。

三条原则（也是本项目的验收底线）：

1. **不新增导航模式**：不给你一套“虚拟光标”或“朗读模式”去操作游戏，
   而是让游戏本来就有的键盘操作能读出来。
2. **不改游戏内容**：不修改剧情、存档、资源文件；卸载后游戏和原版完全一样。
3. **不假装成功**：没测过的功能会明确写“待实测”，不会写成“已支持”。

## 安装前需要准备

- 一份**正版**《露西 -她所期望的一切-》中文版 Ver 1.14，已经能正常启动。
- 一个读屏软件：NVDA（推荐，免费）或争渡读屏；也可以先用 Windows 自带的 SAPI 语音。
- 知道游戏安装目录（Steam 版一般是
  `...\steamapps\common\` 下对应的游戏文件夹；以你机器上的实际路径为准）。

## 安装

安装器会把游戏目录里的 `d3dx9_40.dll` **改名为 `d3dx9_40.orig.dll` 备份起来**，
再把补丁自己的 `d3dx9_40.dll` 放进去。游戏目录里不会多出别的文件。

### 方式一：用安装脚本（推荐）

1. 先构建或下载发布包，确认 `dist\` 里有补丁的 `d3dx9_40.dll`。
2. 以普通权限打开 PowerShell，在仓库目录执行：

   ```powershell
   pwsh -File tools\install.ps1 -GameDir "你的游戏目录"
   ```

3. 先加 `-DryRun` 可以“只看不动”，把要做的每一步打印出来但不改任何文件：

   ```powershell
   pwsh -File tools\install.ps1 -GameDir "你的游戏目录" -DryRun
   ```

4. 安装器会在 `%LOCALAPPDATA%\LucyForAccessibility\` 下写一份安装记录
   （游戏路径、补丁版本、文件哈希）和安装日志，卸载时要用到。

### 方式二：手动安装

1. 关闭游戏。
2. 打开游戏目录，把 `d3dx9_40.dll` 改名成 `d3dx9_40.orig.dll`。
   （如果已经有 `d3dx9_40.orig.dll`，说明之前装过，先看下面的卸载。）
3. 把补丁包里的 `d3dx9_40.dll` 复制进游戏目录。
4. 启动游戏。

> 注意：**不要**用网上下载的 DLL 替换文件，也不要删除 `d3dx9_40.orig.dll`；
> 它是原文件的唯一备份，删除后只能靠 Steam 校验完整性找回。

## 按键说明

补丁自己新增的按键很少，目的就是尽量沿用游戏原生键位（详见
[docs/操作约定.md](docs/操作约定.md)）。

| 功能 | 按键 | 状态 |
|---|---|---|
| 开 / 关朗读 | 待定稿 | 待实测 |
| 重读当前这一句 / 当前这一项 | `Backspace` | 待实测 |
| 切换语音后端（NVDA / 争渡 / SAPI） | `Alt+Shift+F9` | 待实测 |
| 浏览上一项 / 下一项 | 沿用游戏原生键位 | 待实测 |
| 确认 / 激活 | `Enter` 或 `Space` | 待实测 |
| 返回 / 取消 | `Esc` | 待实测 |
| 选择第 1～9 个选项 | 数字键 `1`～`9` | 待实测 |

说明：上表写“待实测”的条目，意思是**键位已经定了，但还没在实机上逐项验证**。
实测后会补上“在哪个界面生效、有没有和游戏原生键冲突”。

## 怎么玩

- 游戏怎么操作，补丁就怎么操作：用游戏原生的方向键 / Enter / Esc 走菜单和选项。
- 当前朗读的，永远是**游戏自己选中的那一项**——不会出现“读屏念的和画面选中的不一样”。
- 剧情文字会在出现时自动朗读；一句没听清就按 `Backspace` 重读。
- 选项出现时，读屏会念出每个选项的内容，按数字键或方向键选择，`Enter` 确认。

不提供“导航模式 / 朗读模式 / 虚拟光标”。这是本项目的设计目标，不是缺功能：
补丁应当让游戏**本来就有**的键盘操作能读出来，而不是在游戏上面再套一层操作方式。

## 常见问题

完整问答见 [docs/常见问题.md](docs/常见问题.md)。最常见的几条：

- **装了没反应、没声音**：先看安装是否成功（游戏目录里应有 `d3dx9_40.orig.dll`），
  再看日志 `%LOCALAPPDATA%\LucyForAccessibility\`；然后确认语音后端（`Alt+Shift+F9` 切换）。
- **杀毒软件报毒**：DLL 注入类补丁常被启发式误报。本项目开源，可自行构建比对；
  详见 FAQ。不要直接关掉杀软，添加排除即可。
- **游戏提示 version is invalid / 打不开**：多半是补丁版本与游戏版本不匹配，
  或复制了 64 位 DLL。用 `tools\uninstall.ps1` 还原后重新安装。

## 已知限制

- 仅支持中文版 Ver 1.14；其他版本**未实测**，可能不工作。
- 当前覆盖范围：剧情 / 选项 / 主菜单 / 设置菜单 **待实测**；
  存档、读档、回想、CG 鉴赏等界面 **待实测**。
- 语音后端中，NVDA 与 SAPI 的可用性**待实测**；争渡只做动态调用，不做运行库捆绑。
- 游戏自带的结局 / 片尾等特殊演出 **待实测**。
- 补丁不包含任何游戏文件、剧情文本、图片或音频。

## 卸载

1. 关闭游戏。
2. 运行：

   ```powershell
   pwsh -File tools\uninstall.ps1 -DryRun   # 先看要做什么
   pwsh -File tools\uninstall.ps1
   ```

3. 卸载器会先核对哈希，确认游戏目录里的 `d3dx9_40.dll` 确实是本补丁装进去的，
   然后删除它、把 `d3dx9_40.orig.dll` 改回 `d3dx9_40.dll`，最后删掉安装记录。

手动卸载：删除游戏目录里的 `d3dx9_40.dll`，把 `d3dx9_40.orig.dll` 改回
`d3dx9_40.dll`。不需要改注册表，也不会留下存档改动。
