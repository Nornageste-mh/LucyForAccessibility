# 露西 -她所期望的一切- 无障碍补丁

一句话：让《露西 -她所期望的一切-》中文版能用读屏软件（NVDA / 争渡 / SAPI）
朗读剧情和界面，全程只用键盘操作，并且**不新增任何导航模式**。

- 当前版本：**0.2.4.0**（开发中）
- 支持游戏：中文版 Ver 1.14（引擎 nkNovel 1.50，32 位，D3D9）
- 已实测平台：Windows 10 64 位 + 32 位游戏进程
- 项目性质：非官方、免费、开源（MIT），与游戏开发商、发行商无关联

> 本文按本机实测结论写。没验证过的内容会明确写「未实测」，
> 而不是当成已经可用。暂停菜单、设置、存读档、选项、确认框都能用键盘操作；
> **标题画面开始游戏这一环还是未打通**（须先点一次鼠标），往下看「已知限制」。
> 历史界面只做了放行（未朗读）。

## 它能做什么

原版游戏的界面本来只认鼠标：标题、设置、存档……用键盘完全没反应；
剧本页面也只认少数几个键。这个补丁是一个 32 位 DLL，替换游戏目录里的
`d3dx9_40.dll` 进入游戏进程，然后：

- 把**剧情文字**抓出来交给读屏朗读（无配音的旁白自动读）；
- 把**界面**变成能用键盘操作：方向键移动、`Enter` 确认（补丁在游戏进程内合成
  鼠标消息，让按钮保持按下约 2 秒引擎才认，所以每次激活要约 2.2 秒）；
- 已用键盘跑通的界面：**暂停菜单**（帮助 / 跳过 / 历史 / 保存 / 读取 / 选项 /
  标题 / 返回游戏共 8 项）、**设置页**（5 条滑条 + 韩 / 日语言 + 全屏开关）、
  **存读档页**（4×3 格 × 10 页）、**确认框**（是 / 否）、**剧情选项屏**；
- 识别**剧情选项**和**确认框**：选项出现时朗读「选项，共 N 项……」并逐项朗读，
  上下键选择、`Enter` 确认；确认框自动朗读游戏原话，上下键在「是 / 否」之间选择；
- 存读档界面按 **4×3 格 × 10 页**建模，方向键选格并朗读格子位置与存档位编号，
  `Enter` 打开 / 保存；存档写在 `游戏目录\Saves\`（游戏自己写，卸载不清）；
- 提供**重读**：一句没听清按 `Backspace`，想往上翻按 `Ctrl+Backspace`；
- 提供**语音后端切换**：`Alt+Shift+F9` 在 NVDA → 争渡 → SAPI 之间切换。

三条原则也是本项目的验收底线：

1. **不新增导航模式**：不需要按任何键切换「朗读模式」「浏览模式」，
   方向键就是操作界面，和用鼠标的玩家看到的是同一套界面。
2. **不改游戏内容**：不碰剧情、不直接改写存档（`游戏目录\Saves\`）与设置
   （`Config.nkenv`）——存档 / 设置由游戏自己写，卸载后游戏回到安装前状态
   （存档和设置是玩家自己的数据，卸载**不会清除**它们）。
3. **不假装成功**：没做成、没测过的功能会直接写出来，不写成「已支持」。

## 安装

需要一份**正版**中文版 Ver 1.14，并且已经能正常启动。

### 方式一：用安装脚本（推荐）

发布包里有 `tools\install.ps1`。先干跑看计划，再正式安装：

```powershell
pwsh -File tools\install.ps1 -GameDir "你的游戏目录" -DryRun
pwsh -File tools\install.ps1 -GameDir "你的游戏目录"
```

安装器会自动先备份原文件，再放补丁；只动这个游戏目录，不需要管理员权限。
它会拒绝：目录不是这个游戏、游戏正从该目录运行、当前 DLL 不是原版
（比如已经装了别的补丁或文件损坏）。重复运行只会提示「已安装」，不会破坏备份。

卸载：

```powershell
pwsh -File tools\uninstall.ps1 -GameDir "你的游戏目录"
```

（先加 `-DryRun` 可以只看计划；确认强制还原加 `-Force`；连日志一起删加 `-PurgeLogs`。）

### 方式二：手动安装（备选）

1. 关闭游戏。
2. 打开游戏安装目录。
3. 把 `d3dx9_40.dll` 改名为 **`d3dx9_40_orig.dll`**（这是游戏原来的文件，留作备份）。
4. 把补丁的 `d3dx9_40.dll` 复制进游戏目录。
5. 启动游戏。标题画面用 `↑` `↓` 选、`Enter` 开始（补丁会合成约 2.2 秒的鼠标点击，
   并按游戏要求把真实光标移到按钮上）；进入剧情后即可全程键盘。

> `d3dx9_40_orig.dll` 是原文件的唯一备份，**不要删**。
> 误删了可以用 Steam「验证游戏文件完整性」找回。

安装后游戏目录里会多出这些文件：

```
游戏目录\
  d3dx9_40.dll          ← 补丁
  d3dx9_40_orig.dll     ← 游戏原文件备份
  a11y\
    a11y.log            ← 补丁运行日志
    install.json        ← 安装记录（脚本安装时生成）
    install.log         ← 安装日志（脚本安装时生成）
    config.ini          ← 补丁配置
    nvdaControllerClient.dll  ← 调 NVDA 用的组件
```

## 怎么玩（键位表）

### 剧情页（游戏原生键位，补丁不改）

| 功能 | 按键 |
|---|---|
| 下一句 | `ENTER` |
| 显示 / 隐藏对话框 | `SPACE` |
| 跳过 | `Z` 或长按 `CTRL` |
| 下一页 / 上一页 | 滚轮下 / 滚轮上 |
| 对话历史 | 滚轮上 |
| 暂停菜单 | `ESC` 或右键 |

### 补丁新增（只用游戏没占用的键）

| 功能 | 按键 | 状态 |
|---|---|---|
| 重读当前句 | `Backspace` | 已实现，实机可用 |
| 往上翻历史句 | `Ctrl+Backspace` | 已实现，实机可用 |
| 切换语音后端（NVDA → 争渡 → SAPI） | `Alt+Shift+F9` | 已实现，实机可用 |

### 菜单 / 界面（补丁拟态）

| 功能 | 按键 |
|---|---|
| 在界面项之间移动 | 方向键 `↑ ↓ ← →` |
| 选中当前项 | `ENTER` |
| 返回 / 关菜单 | `ESC` |
| 高风险项（退出游戏 / 回标题 / 切语言） | `ENTER` 连按两次才执行 |

键盘已经跑通的界面：

- **暂停菜单** 8 项：帮助 / 跳过 / 历史 / 保存 / 读取 / 选项 / 标题 / 返回游戏；
- **设置页**：5 条滑条（用 ← / → 调整，朗读会带上游戏画出来的数值）、
  韩 / 日语言切换、全屏开 / 关；
- **存读档页**：4×3 格 × 10 页，方向键选格，读出「第 N 页，第 r 行第 c 列，
  存档位 NN」（NN = 20×(页−1) + 4×行 + 列），`Enter` 打开 / 保存；
- **确认框**：读档 / 存档 / 删除进度 / 回标题时出现，`↑` `↓` 在「是 / 否」之间，
  `Enter` 确认，`ESC` 等于选「否」。

> 菜单项按 `Enter` 后要约 **2.2 秒**才生效：游戏的 `Engine.dll` 不调用
> `GetCursorPos` / `SetCursorPos` / `SendInput`，指针位置靠 `WM_MOUSEMOVE` 的
> lParam，按键状态靠 `GetAsyncKeyState` 轮询。补丁只能投递合成的鼠标消息，
> 并把按钮保持按下约 2000ms 引擎才认（实测按住不到 1s 不认、2000ms 才生效）。
> 这期间按键会被忽略——是引擎读输入的方式决定的，不是卡顿；
> 点击在后台线程排队执行，不阻塞键盘钩子。

### 选项与确认框（补丁拟态）

| 场景 | 操作 |
|---|---|
| 剧情选项（首个选项屏两个分支条已实测） | 听到「选项，共 N 项，上下键选择，回车确定」后，`↑` `↓` 选择，`Enter` 选中分支（无确认框），`Esc` 取消回剧情 |
| 确认框（读档 / 存档 / 删除进度 / 回标题） | 自动朗读游戏原话，`↑` `↓` 在「是 / 否」之间，`Enter` 确认，`Esc` 等于选「否」；关闭后不会反复触发 |
| 选项朗读 | 选项出现后 250ms 内进入选项模式，逐项朗读；选项文字会进重读缓冲区 |

### 朗读规则（实测）

- **带配音的台词不自动朗读**（包括角色名）：这类文本只放进重读缓冲区，
  按 `Backspace` 才读，避免和角色语音打架。
  判据**已实机初步验证**：0.2.4.0 读档后连按 40 行，48 句台词中 3 句判为配音
  且静默（「脉搏正常 . . .」「指纹登录完毕。」「「哎？」」），其余 45 句照常朗读。
- **没有配音的旁白自动朗读**。
- **选项文字会进重读缓冲区**（重读只含剧情文本与选项）。
- **菜单 / 界面名只朗读**，不进重读缓冲区（`Backspace` 不会念出过期的菜单项）。
- **同一句不会反复念**（去重环 32 条、时效窗口 120 秒）；纯标点行（如「………」）
  和打字机动画碎屑（「P…I…」）不朗读。
- 存读档格子位置读作「第 N 页，第 r 行第 c 列，存档位 NN」；
  空档位会念「这个存档位是空的」；点存档后会等确认框 3.5 秒再判断是否成功。
- 菜单滑条 / 开关的播报会带上游戏画出来的数值；读不到数值时只播标签（格式**未实测**）。
- 菜单播报同时写进 `a11y\a11y.log`（`menu: announce "…"`），便于反馈问题时对照。

## 已知限制

- **0.2.4.0 未验证完整通关**：剧情页、暂停菜单、设置、存读档、选项、确认框
  都能用键盘操作，但存读档的完整落盘 / 读回没有逐项验证，
  **历史界面只把滚轮放行给游戏（补丁不朗读）**。
  详见 [docs/project_status.md](docs/project_status.md) 第 5 节。
- 配音判据是**启发式**的，有两类误差：与台词同刻开始的音乐 / 音效可能被误判成配音
  （后果 = 该句不自动朗读，按 `Backspace` 可听）；语音若延迟超过 900ms 才开始，
  会被当成旁白自动朗读。
- 切换语音后端、重读这两个键**若与游戏原生键冲突，未测**。
- 存档（`游戏目录\Saves\`）与设置（`Config.nkenv`）是游戏自己写的，
  卸载补丁**不会清除**它们。
- 存读档格子的存档内容（时间、章节）**尚未朗读**。
- 菜单项激活要约 **2.2 秒**才生效（见上文「菜单 / 界面」），这期间按键会被忽略。
- 游戏自带的**画面说明页是图片**，没有文字可抓，补丁读不出来；替代方案**未实测**。
- 只测了**简体中文**；其他语言版本**未实测**。
- 所有界面靠「画面矩形」近似判断当前项，个别界面可能读的和画面高亮的不是同一项
  （**待逐界面核对**）。

## 常见问题

完整问答见 [docs/常见问题.md](docs/常见问题.md)。最常见的几条：

- **装了没反应、一片安静**：先确认游戏目录里有 `d3dx9_40_orig.dll`（说明装过），
  再看 `游戏目录\a11y\a11y.log`，然后确认读屏软件在运行，按 `Alt+Shift+F9` 依次切后端试试。
- **杀毒软件报毒**：DLL 注入类补丁常被误报。本项目开源、可自行构建比对；
  把补丁 DLL 加排除项即可，不要直接关掉杀毒软件。
- **为什么有配音的地方不读**：设计如此（见上面「朗读规则」），按 `Backspace` 可听。
- **为什么开始游戏还要先点一下鼠标**：标题画面这一环补丁还没打通，先用鼠标点
  「开始」，进去之后就能全程键盘了（见「已知限制」第一条）。
- **按 `Enter` 后要等 2 秒多才动**：菜单项激活时补丁要让按钮保持按下约 2000ms
  引擎才认，所以每次激活约 2.2 秒；这期间按键会被忽略，属正常现象（不是死机）。
- **存档能用吗**：存读档界面可以用键盘操作（4×3 格 × 10 页）；读档已实测，
  存档流程在修正等待时间后可用，但完整落盘 / 读回还没逐项验证。

## 卸载

1. 关闭游戏。
2. 删除游戏目录里的 `d3dx9_40.dll`（补丁）。
3. 把 `d3dx9_40_orig.dll` 改回 `d3dx9_40.dll`。
4. `a11y\` 文件夹可以整个删掉（只是补丁的日志和配置）。

不需要改注册表；存档（`游戏目录\Saves\`）和设置（`Config.nkenv`）不会被动过。
更细的步骤见 [docs/安装说明.md](docs/安装说明.md)。

## 给开发者

- 结构：`src/`（补丁源码）、`build/`（构建与发布）、`tools/`（安装 / 卸载脚本）、
  `docs/`（文档）、`dist/`（构建产物，不入库）。
- 构建：设置环境变量 `VCVARS` 指向 `vcvars32.bat` 后运行 `build\build.cmd`
  （`build\build.cmd dev` 为开发版，带调试通道，不会进入发布包）。
- 发布：`build\release.ps1`（三道守卫：版本号四段、无调试通道、DLL 必须是 x86）。
- 提交前：`build\check-staged.ps1`。
