# 常见问题（露西 -她所期望的一切- 无障碍补丁）

> 当前版本 0.2.0.0 是骨架，以下回答里「怎么查」的部分已经可用，
> 「应该是……」的结论全部**待实测**，会随实机结果更新。

## 装了没反应 / 一片安静

按顺序查：

1. 游戏目录里是否有 `d3dx9_40.orig.dll`（有 = 安装器动过文件）。
2. 游戏是否真的加载了补丁：看补丁日志（`%LOCALAPPDATA%\LucyForAccessibility\`，
   具体文件名待定稿）。
3. 读屏软件是否在运行、是否选了正确的语音后端（按 `Alt+Shift+F9` 切换后重试）。
4. 系统是否有可用的中文语音（SAPI 后端需要）。
5. 游戏版本是否中文版 Ver 1.14；其他版本未实测。

## 杀毒软件报毒

DLL 注入类补丁被启发式引擎误报很常见。处理建议：

- 不要直接关闭杀毒软件。
- 把补丁 DLL 加入排除项，或先还原游戏、只在需要时临时启用。
- 本项目开源，可以按 `build\build.cmd` 自己从源码构建，与发布包比对哈希。
- 若杀软报的是「游戏目录里的原版文件」，那是游戏自带的，与本补丁无关。

## 游戏提示 version is invalid / 打不开

- 常见原因：补丁版本与游戏版本不匹配；或误放了 64 位 DLL。
- 处理：先 `tools\uninstall.ps1` 还原，确认原版能启动，再重新安装匹配版本。
- 仍然不行：附日志反馈（版本、读屏软件、日志文件）。

## 朗读重叠 / 一句话念两遍

- 可能是补丁与读屏软件同时播报，或界面切换时重复触发。
- 先按 `Backspace` 重读判断是否重复；再按 `Alt+Shift+F9` 换后端对比。
- 若稳定复现，请记录：界面、操作、读屏软件版本，附日志反馈。

## 快进 / 自动播放时没有朗读

- 快进会跳过大量文本，补丁是否朗读**待实测**。
- 先把快进停下，用正常速度确认基础朗读是否正常。

## 选项有时间限制，来不及听

- 是否暂停计时**待实测**。
- 当前建议：先确认选项朗读正常；有计时压力的选项如需暂停，会作为遗留缺陷
  明确写进发布说明，不假装已解决。

## 按钮只读出「按钮」两个字

- 说明控件本身没有可读文本，补丁的标签回退顺序（游戏文本 → 父级标题 → 提示 →
  已核实映射 → 清理后的对象名）会依次尝试。
- 若仍然只读类型，请记录界面与位置反馈；这是已知的待改进点。

## 为什么没有「导航模式」/「朗读模式」

这是设计目标，不是缺功能：补丁要让游戏**本来就有**的键盘操作能读出来，
而不是在游戏上面套一层新模式。详见 [操作约定.md](操作约定.md)。

## 会不会被 Steam / 开发商封号

- 本补丁只替换游戏目录里的 DLL、不联网、不改存档，也不绕过 DRM；
  但第三方修改是否被允许，最终以游戏与平台条款为准。
- 请使用正版游戏；盗版不受支持，也不提供帮助。

## 卸载后游戏会变吗

不会。卸载器把原 `d3dx9_40.dll` 改名还原，并删除补丁文件与安装记录；
游戏目录回到安装前状态。手动卸载见 [安装说明.md](安装说明.md) 第 8 节。

## 日志在哪

`%LOCALAPPDATA%\LucyForAccessibility\`（安装记录与安装日志）。
补丁运行日志文件名待定稿。反馈问题时请附日志、游戏版本、补丁版本、读屏软件版本。
