# 《露西 -她所期望的一切-》操作约定（逐作填写）

> 依据：`Framework/docs/操作逻辑公约.md`。
> **P0 起草、P3 定稿、P4 用测试问卷核对。**
> 本版 `0.2.4.0`：键位与朗读策略已按本机实测填写；写「未实测」的地方还没测过，
> 不是已经成立的事实。

## 1. 采用情况

- 交互形态判定：□ A □ B ☑ **C**（详见 [交互形态判定.md](交互形态判定.md) §1）
- 界面键盘来源：**补丁拟态**——界面本身不响应键盘，补丁把方向键 / Enter
  翻译成鼠标消息（进程内 `PostMessage` 合成移动 + 按下），模拟玩家用鼠标点击；
  补丁不新增模式开关。
- 激活级别（公约 §2）：**第 2 级**（向游戏界面派发鼠标消息；1 直接调动作方法
  不可用，因为游戏没有可调用的界面动作函数，也没有控件模型）。
- 是否使用遗留导航模式：**否**（无模式开关；符合本作「无导航模式」目标）。

### 2.3 界面操作（拟态，游戏原生键盘不参与）

| 语义 | 按键 | 说明 | 证据 |
|---|---|---|---|
| 移动虚拟光标 | `↑` `↓` `←` `→` | 按矩形中心最近方向在界面项之间移动；不改变游戏选项 | 实测 |
| 激活当前项 | `Enter` | 翻译成合成鼠标点击当前项；按钮保持按下约 2000ms 引擎才认，**每次约 2.2 秒后生效**（见下） | 实测 |
| 返回 / 关闭菜单 | `Esc` | 拟态返回；具体等价于哪个界面动作未实测 | 实测（键可用） |
| 高风险项二次确认 | `Enter` 连按两次 | 退出游戏 / 回标题 / 切语言等高风险项必须连按两次才执行，防误触 | 实测 |
| 剧情选项 | `↑` `↓` 选择，`Enter` 选中 | 补丁识别画面文字后 250ms 内自动进入选项模式并逐项朗读；首个选项屏（2 个分支条）实测选中成立、无确认框 | 实测 |
| 确认框（是 / 否） | `↑` `↓` 选择，`Enter` 确认，`Esc` 等于「否」 | 自动朗读游戏原话；关闭后 400ms 时效 + 3s 静默，不会反复触发 | 实测 |
| 调整滑条数值 | `←` `→` | 设置页 5 条滑条可调；播报带游戏画出来的数值，读不到数值时只播标签 | 实测（播报格式未实测） |
| 语言 / 全屏开关 | `Enter` 激活 | 设置页韩 / 日语言、全屏开 / 关；切语言属高风险项，需连按两次 | 实测 |
| 存档位选择 | `↑` `↓` `←` `→`，`Enter` | 4×3 格 × 10 页；存档位编号 NN = 20×(页−1) + 4×行 + 列 | 实测（读档实测、存档落盘未逐项实测） |
| 数字键快速选选项 | 未实现 | 选项本身已可用（方向键选择）；数字键直达未实现 | 未实现 |

> 菜单项激活要等待约 **2.2 秒**：`Engine.dll` 的 USER32 导入表没有
> `GetCursorPos` / `SetCursorPos` / `SendInput`，界面靠 `WM_MOUSEMOVE` 的 lParam
> 定位置、靠 `GetAsyncKeyState` 轮询按钮；补丁只能 `PostMessage` 合成鼠标消息并让
> 按钮保持按下约 2000ms（实测按住不到 1s 引擎不认、2000ms 成立）。这期间按键会被忽略，
> 属引擎行为，不是卡顿。点击由 tick 线程排队，不阻塞键盘钩子。

**游戏原生占用键**（补丁不抢，也不拿来当重读键）：

| 键 | 游戏里的作用 |
|---|---|
| `ENTER` / `SPACE` / `Z` / 长按 `CTRL` / `ESC` / 右键 / 滚轮 | 剧情页推进、跳过、开暂停菜单等（见 2.1） |

|---|---|---|---|
| `Tab` 焦点遍历 | 游戏界面没有控件模型，没有可遍历的焦点链 | 用方向键移动拟态光标 | 否（不采用） |
| 数字键快速选选项 | 数字键直达未实现 | 选项模式下用 `↑` `↓` 选择后 `Enter` | 否（无必要） |
| 历史界面朗读 | 补丁只把滚轮放行给游戏，不朗读历史 | 暂无（未实测） | 是（见交互形态判定 §5） |
| 朗读画面说明页（图片） | 内容是图片，抓不到文字 | 暂无替代方案（未实测） | 是（见交互形态判定 §5） |

## 4. 朗读策略、焦点与撤销

### 4.1 朗读策略（实测确定）

- **带配音的剧情文本不自动朗读**（包括角色名）：只放进重读缓冲区，
  玩家按 `Backspace` 才朗读。原因：不跟角色语音打架。
  判据**已实机初步验证**（0.2.4.0）：读档后连按 40 行，48 句台词里 3 句判为配音
  且静默——「脉搏正常 . . .」「指纹登录完毕。」「「哎？」」，其余 45 句照常朗读。
  判据是启发式的（`nekoHWMusic::play` 钩子：台词行开始 900ms 内孤立播放、
  `dur_ms>=1500`、`size>=15000`），两类误差见项目状态页第 5 节。
- **无配音的旁白自动朗读**。
- **选项文字会进重读缓冲区**（重读只含剧情文本与选项）。
- **菜单 / 界面名只朗读，不进重读缓冲区**：避免 `Backspace` 念出过期的菜单项。
- **同句去重**：去重环 32 条、时效窗口 120 秒，同一句不会被反复念。
- **纯标点行**（如「………」）不朗读；**打字机碎屑**（「P…I…」逐字动画）不朗读。
- **菜单播报同时写 `a11y\a11y.log`**（`menu: announce "…"`）。
- **重读缓冲区**：`Backspace` 读当前句；`Ctrl+Backspace` 往上翻更早的句子。
- 每句进缓冲区时按顺序保存，翻到最早一句再按 `Ctrl+Backspace` 的行为未实测。

### 4.2 界面朗读表示法

- 存读档格子位置：读作「**第 N 页，第 r 行第 c 列，存档位 NN**」
  （NN = 20×(页−1) + 4×行 + 列），方便定位。
- 点空存档位：念「**这个存档位是空的**」；点存档格后补丁会等确认框 **3.5 秒**
  再判断，没有弹框才念「**已保存**」（原先 0.9 秒会误报）。
- 菜单滑条 / 开关：播报会带上游戏画出来的数值；读不到数值时只播标签；
  具体播报格式（是否带单位、百分比）**未实测**。
- 高风险项（退出游戏 / 回标题 / 切语言）：第一次 Enter 只提示，再按一次才执行。

### 4.3 焦点与撤销

- **菜单屏幕跟随（实测）**：玩家用鼠标 / 读档 / 自动模式绕开补丁时，补丁依据画面上的
  剧情文字在 2.5 秒内把状态拉回剧情页。
- 虚拟光标的初始位置：进入界面时默认选哪一项**未实测**。
- 当前项与画面高亮是否一致：按矩形近似，**未实测**（逐界面核对中）。
- 重复播报抑制：是否抑制程序化焦点造成的重复朗读**未实测**。
- 离开界面时的焦点恢复 / 输入订阅撤销：**未实测**。
- 延迟朗读的取消条件（切界面 / 快进 / 选项超时）：**未实测**。
