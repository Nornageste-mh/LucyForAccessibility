# 安装说明（露西 -她所期望的一切- 无障碍补丁）

本补丁是非官方作品，只支持**正版**《露西 -她所期望的一切-》中文版 Ver 1.14。
它不修改游戏本体、剧情，也不直接改写存档与设置；卸载后游戏文件回到安装前原样
（存档与设置是玩家自己的数据，会保留）。

> 当前版本 `0.2.4.0`（开发中）。本说明按本机实测写，
> 没测过的内容会明确写「未实测」。

## 1. 它做了什么

游戏目录里有一个 `d3dx9_40.dll`，是游戏自带的 DirectX 运行库；
Windows 加载 DLL 时**优先用同目录里的同名文件**。补丁就用这个机制进入游戏：

1. 把游戏原来的 `d3dx9_40.dll` 改名为 **`d3dx9_40_orig.dll`** 保留（原文件备份）；
2. 把补丁自己的 `d3dx9_40.dll` 放进游戏目录；
3. 游戏启动时加载补丁，补丁再把需要的调用转给备份的原文件，
   所以画面、声音、存档都照常。

补丁运行时的日志和配置放在**游戏目录的 `a11y\` 文件夹**里：

```
游戏目录\
  d3dx9_40.dll          ← 补丁（替换品）
  d3dx9_40_orig.dll     ← 游戏原文件（备份，别删）
  a11y\
    a11y.log            ← 补丁运行日志（反馈问题时附上）
    config.ini          ← 补丁配置
    nvdaControllerClient.dll  ← 调 NVDA 用的组件
```

- 不向系统目录写文件，不改注册表，不装服务。
- 不直接改写存档（`游戏目录\Saves\`）和游戏设置（`Config.nkenv`）——这两处由游戏
  自己写；卸载补丁**不会清除**它们。
- 不包含任何游戏文件、剧情文本、图片或音频。

## 2. 安装前

1. 确认游戏能正常启动、能正常玩（先排除游戏自身问题）。
2. 关闭游戏，以及 Steam 的「游戏内覆盖」等可能占用文件的功能。
3. 确认你拿到了补丁的 `d3dx9_40.dll`（发布包或自己构建的产物）。
4. 确认系统是 Windows 10 / 11；本补丁只在 **32 位游戏进程**里工作
   （已实测平台：Windows 10 64 位 + 32 位游戏进程）。

## 3. 安装（手动）

1. 关闭游戏。
2. 打开游戏安装目录。
3. 把 `d3dx9_40.dll` 改名为 **`d3dx9_40_orig.dll`**。
   - 如果已经有 `d3dx9_40_orig.dll`，说明之前装过：先按第 6 节还原，再装。
   - **不要**直接删除原文件，也不要用网上下载的 DLL 替换。
4. 把补丁的 `d3dx9_40.dll` 复制进游戏目录。
5. 启动游戏。标题画面用 `↑` `↓` 选、`Enter` 开始（补丁合成约 2.2 秒的鼠标点击，
   并把真实光标移到按钮上）；进入剧情之后即可全程键盘（见第 7 节）。

## 4. 安装脚本（推荐）

仓库（或发布包）里有 `tools\install.ps1` / `tools\uninstall.ps1`。
它们只动你指定的游戏目录，不需要管理员权限，不装服务、不写注册表。

```powershell
# 先干跑，只打印计划，不改任何文件
pwsh -File tools\install.ps1 -GameDir "你的游戏目录" -DryRun

# 确认无误后正式安装
pwsh -File tools\install.ps1 -GameDir "你的游戏目录"
```

- `-SourceDir`：补丁文件 `d3dx9_40.dll` 所在目录；默认是脚本所在包的上一级
  （发布包根目录）。从仓库直接用时，可以指向 `build\out` 或 `dist`。
- 安装器会检查：目录里有 `Lucy.exe` + `Engine.dll`；游戏没有从该目录运行；
  `d3dx9_40.dll` 的 SHA256 是原版（`16FD909A…E216B`）。
- 拒绝安装的情况：目录不是这个游戏、游戏正从该目录运行、
  当前 DLL 不是原版（可能装了别的补丁或文件损坏，会提示先用 Steam 验证完整性）。
- 已经装过再运行：只提示「已安装」，**不会覆盖备份**。
- 安装后游戏目录：`d3dx9_40.dll`（补丁）、`d3dx9_40_orig.dll`（原文件备份）、
  `a11y\`（`install.json` 安装记录、`install.log` 安装日志、
  `nvdaControllerClient.dll` 若包内有）。

卸载：

```powershell
pwsh -File tools\uninstall.ps1 -GameDir "你的游戏目录" -DryRun   # 先看计划
pwsh -File tools\uninstall.ps1 -GameDir "你的游戏目录"
```

- 卸载器先用 `a11y\install.json` 里的哈希确认当前 DLL 确实是本补丁装的；
  哈希不符会拒绝（确认要强制还原才加 `-Force`）。
- 还原后校验原文件哈希；删除 `a11y\install.json` 与 `a11y\nvdaControllerClient.dll`，
  **保留日志** `a11y\install.log`、`a11y.log`；加 `-PurgeLogs` 才会删掉整个 `a11y\`。
- 备份文件不在了又无法确认状态时，脚本会报错并说明手动恢复办法
  （Steam「验证游戏文件完整性」）。

> 自测情况：安装 / 卸载已在游戏副本目录上做端到端实测（安装、重复安装、
> 卸载、干跑、哈希不符拒绝、游戏运行中拒绝），**真实游戏目录尚未实测**。

## 5. 三个常见坑

- **标题画面按 `Enter` 约 2.2 秒后才生效**：补丁用合成鼠标点击，标题按钮要求真实光标
  停在按钮上（补丁在点击阶段同步移动光标）。没反应就再按一次 `Enter`。
- **复制了 64 位 DLL**：32 位游戏加载 64 位 DLL 会静默失败（表现为「补丁没反应」）。
  发布包里的 DLL 必须是 32 位；`build\release.ps1` 会自动校验 PE 架构。
- **杀毒软件报毒**：DLL 注入类补丁常被启发式误报。本项目开源、可自行构建比对；
  详见 [常见问题.md](常见问题.md) 的「杀毒软件报毒」。不要直接关掉杀毒软件。

### 技术说明：为什么菜单项按 Enter 要约 2.2 秒才生效

`Engine.dll` 的 USER32 导入表里没有 `GetCursorPos` / `SetCursorPos` / `SendInput`：
界面靠 `WM_MOUSEMOVE` 消息的 lParam 定指针位置，按钮状态靠 `GetAsyncKeyState`
轮询。在进程内注入硬件鼠标对它无效，所以补丁只能 `PostMessage` 合成鼠标消息，
并让按钮保持按下约 **2000ms**——实测按住不到 1 秒引擎不认，2000ms 才生效。

所以用补丁操作菜单时，每激活一项要约 **2.2 秒**才生效，这期间按的键会被忽略。
这是引擎取输入的方式决定的，**不是卡顿或死机**；点击由补丁的后台线程排队驱动，
不会卡住键盘钩子。

## 6. 卸载 / 还原

1. 关闭游戏。
2. 删除游戏目录里的 `d3dx9_40.dll`（这是补丁）。
3. 把 `d3dx9_40_orig.dll` 改回 `d3dx9_40.dll`。
4. `a11y\` 文件夹可以整个删除（只是补丁的日志与配置，不影响游戏）。
   用脚本安装的，`a11y\install.json` 也在里面，删掉不影响游戏。

用卸载脚本一条命令即可（见第 4 节）；手动步骤如上。

卸载后游戏文件回到安装前状态：不残留代理 DLL。存档（`Saves\`）和设置
（`Config.nkenv`）是游戏自己写的玩家数据，卸载**不会清除**。
如果备份文件被误删了，可以用 Steam「验证游戏文件完整性」找回原文件。

## 7. 按键说明

### 剧情页（游戏原生键位，补丁不改）

| 功能 | 按键 |
|---|---|
| 下一句 | `ENTER` |
| 显示 / 隐藏对话框 | `SPACE` |
| 跳过 | `Z` 或长按 `CTRL` |
| 下一页 / 上一页 | 滚轮下 / 滚轮上 |
| 对话历史 | 滚轮上 |
| 暂停菜单 | `ESC` 或右键 |

### 补丁新增键（只用游戏没占用的键）

| 功能 | 按键 |
|---|---|
| 重读当前句 | `Backspace` |
| 往上翻历史句 | `Ctrl+Backspace` |
| 切换语音后端（NVDA → 争渡 → SAPI） | `Alt+Shift+F9` |

### 菜单 / 界面（补丁拟态，没有导航模式）

| 功能 | 按键 |
|---|---|
| 在界面项之间移动 | 方向键 `↑ ↓ ← →` |
| 选中当前项 | `ENTER`（约 2.2 秒后生效） |
| 返回 / 关菜单 | `ESC` |
| 高风险项（退出游戏 / 回标题 / 切语言） | `ENTER` 连按两次才执行 |

键盘已跑通的界面：**暂停菜单** 8 项（帮助 / 跳过 / 历史 / 保存 / 读取 / 选项 /
标题 / 返回游戏）、**设置页**（5 条滑条 + 韩 / 日语言 + 全屏开关）、
**存读档页**（4×3 格 × 10 页，读「第 N 页，第 r 行第 c 列，存档位 NN」，
NN = 20×(页−1) + 4×行 + 列）、**确认框**、**首个选项屏**。
标题画面开始游戏**已可用键盘**（`↑` `↓` 选、`Enter` 开始，0.2.4.0 实机验证）。

### 选项与确认框（补丁拟态）

| 场景 | 按键 |
|---|---|
| 剧情选项 | `↑` `↓` 选择，`ENTER` 选中（无确认框），`ESC` 取消回剧情 |
| 确认框（读档 / 存档 / 删除进度 / 回标题） | `↑` `↓` 在「是 / 否」之间，`ENTER` 确认，`ESC` 等于选「否」；关闭后不会反复触发 |

**没有「导航模式 / 朗读模式」**：不需要按任何键切换模式，方向键就是操作界面。

## 8. 朗读规则（实测）

- **带配音的台词不自动朗读**（含角色名），按 `Backspace` 才读——避免和角色语音打架。
  判据已实机初步验证（0.2.4.0）：深档读档后连按 40 行，48 句台词里 3 句判为配音
  且静默，其余 45 句照常朗读。判据是启发式的：与台词同刻开始的音乐 / 音效
  可能被误判（该句不自动读，按 `Backspace` 可听）；语音若延迟超过 900ms 才开始，
  会被当旁白自动朗读。
- **没有配音的旁白自动朗读**。
- **选项文字会进重读缓冲区**（重读只含剧情文本与选项）。
- **菜单 / 界面名只朗读，不进重读缓冲区**，`Backspace` 不会念出过期的菜单项。
- **同一句不会反复念**（去重环 32 条、窗口 120 秒）；纯标点行（如「………」）和
  打字机动画碎屑（「P…I…」）不朗读。
- 存读档格子位置读作「第 N 页，第 r 行第 c 列，存档位 NN」；
  空档位会念「这个存档位是空的」；点存档后等确认框 3.5 秒再判断是否「已保存」。
- 菜单滑条 / 开关的播报会带上游戏画出来的数值；读不到数值时只播标签（格式未实测）。
- 菜单播报会同时写进 `a11y\a11y.log`（`menu: announce "…"`），反馈时可用。

## 9. 本作差异

- 代理文件是 `d3dx9_40.dll`（DirectX 9 运行库名），不是其他补丁常见的
  `dinput8.dll` / `version.dll`：游戏同目录优先加载，所以不用改游戏主程序。
- 引擎为 nkNovel 1.50；其他引擎的补丁文件和安装方式不适用。
- 目前只声明支持中文版 Ver 1.14，其他版本**未实测**。
