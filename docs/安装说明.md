# 安装说明（露西 -她所期望的一切- 无障碍补丁）

本补丁是非官方作品，只支持**正版**《露西 -她所期望的一切-》中文版 Ver 1.14。
它不会修改游戏本体、剧情或存档，卸载后游戏和安装前完全一样。

> 当前版本 `0.2.0.0` 是骨架，功能尚未实机验证。本说明随实测更新，
> 标「待定稿」的内容以发布包内的最终版本为准。

## 1. 它做了什么

游戏目录里有一个 `d3dx9_40.dll`。补丁把它**改名备份**为 `d3dx9_40.orig.dll`，
再放入自己的同名 DLL。游戏启动时加载的是补丁；补丁再把调用转给备份的原文件，
所以游戏的渲染、声音不受影响。

- 不会向系统目录写文件，不改注册表，不装服务。
- 不会在游戏目录里留安装记录（记录写在用户目录，见第 7 节）。
- 不包含任何游戏文件、剧情文本、图片或音频。

## 2. 安装前

1. 确认游戏能正常启动、能正常玩（先排除游戏自身问题）。
2. 关闭游戏，以及 Steam 的「游戏内覆盖」等可能占用文件的程序。
3. 确认你有补丁包：`dist\d3dx9_40.dll`（或发布 zip 解压后的同名文件）。
4. 建议先做一次「只看不动」的干跑，确认路径没错：

   ```powershell
   pwsh -File tools\install.ps1 -GameDir "你的游戏目录" -DryRun
   ```

## 3. 安装（脚本）

```powershell
pwsh -File tools\install.ps1 -GameDir "你的游戏目录"
```

安装器会做这些事，任何一步失败都会明确报错并停下（不会留下半装状态）：

1. 检查游戏目录存在、里面有 `d3dx9_40.dll`。
2. 如果 `d3dx9_40.orig.dll` 已存在 → 提示「已经装过」，不重复覆盖。
3. 把 `d3dx9_40.dll` 改名为 `d3dx9_40.orig.dll`。
4. 把补丁的 `d3dx9_40.dll` 复制进去。
5. 计算并记录原文件与补丁文件的 SHA256，写安装记录。

## 4. 安装（手动）

1. 关闭游戏，打开游戏目录。
2. 把 `d3dx9_40.dll` 改名为 `d3dx9_40.orig.dll`。
3. 把补丁包里的 `d3dx9_40.dll` 复制进游戏目录。
4. 启动游戏。没声音时先看第 8 节日志。

## 5. 三个常见坑

- **直接把补丁 DLL 覆盖过去、不备份**：以后卸载只能靠 Steam「校验文件完整性」
  找回原文件。请让安装器改名备份，或手动先改名。
- **复制了 64 位 DLL**：32 位游戏加载 64 位 DLL 会静默失败（表现为「补丁没反应」）。
  发布包里的 DLL 必须是 32 位；用 `build\release.ps1` 构建可自动校验。
- **杀毒软件报毒**：DLL 注入类补丁常被启发式误报。本项目开源、可自行构建比对；
  详见 [常见问题.md](常见问题.md) 的「杀毒软件报毒」。不要直接关闭杀毒软件。

## 6. 已经装过其他补丁

如果游戏目录里已经有 `d3dx9_40.orig.dll`，说明之前装过本补丁或别的同名代理：

1. 先运行 `tools\uninstall.ps1`（或手动还原）回到干净状态。
2. 再按第 3 节安装。

不要同时放两个代理 DLL。

## 7. 安装记录与日志

- 目录：`%LOCALAPPDATA%\LucyForAccessibility\`
- `install.json`：游戏路径、补丁版本、原文件/补丁文件 SHA256、安装时间。
- `install.log`：安装与卸载的步骤日志（排查时请附上）。
- 补丁运行日志：路径待定稿（随补丁版本更新写入本节）。

## 8. 卸载 / 还原

```powershell
pwsh -File tools\uninstall.ps1 -DryRun   # 先看要做什么
pwsh -File tools\uninstall.ps1
```

卸载器会先核对哈希：只有确认游戏目录里的 `d3dx9_40.dll` 是本补丁装的，才会删它、
把 `d3dx9_40.orig.dll` 改回原名，并删除安装记录；哈希不符会拒绝并提示手动处理。

手动卸载：删除游戏目录的 `d3dx9_40.dll`，把 `d3dx9_40.orig.dll` 改回
`d3dx9_40.dll`。

## 9. 热键

| 功能 | 按键 |
|---|---|
| 开 / 关朗读 | 待定稿 |
| 重读当前句 / 当前项 | `Backspace` |
| 切换语音后端（NVDA / 争渡 / SAPI） | `Alt+Shift+F9` |

界面操作沿用游戏原生键位，**没有导航模式**。

## 10. 本作差异

- 代理文件是 `d3dx9_40.dll`（DirectX 9 运行库名），不是其他补丁常见的
  `dinput8.dll` / `version.dll`。
- 引擎为 nkNovel 1.50；其他引擎的补丁文件和安装方式不适用。
- 目前只声明支持中文版 Ver 1.14，其他版本未实测。
