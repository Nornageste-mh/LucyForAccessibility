## 1. 项目概况

- **目标**：让盲人玩家用读屏软件（NVDA / 争渡 / SAPI）全程键盘通关本作，
  且补丁不给游戏新增导航模式或可见界面（Framework 第 0 条纪律）。
- **注入方式**：替换游戏目录里的 `d3dx9_40.dll` 为补丁的代理 DLL，
  原文件由安装器改名为 `d3dx9_40.orig.dll` 备份；卸载时还原。
- **安装入口**：`tools\install.ps1`（支持 `-DryRun`）；**卸载入口**：`tools\uninstall.ps1`。
- **安装记录 / 日志**：`%LOCALAPPDATA%\LucyForAccessibility\`（游戏目录不写额外文件）。
- **设计依据**：`D:\DSHWorkSpace\Framework\README.md`（三条铁律 + 第 0 条纪律）、
  `Framework\docs\操作逻辑公约.md`。
- **构建入口**：`build\build.cmd`（32 位，`dev` 参数为开发版）；
  **发布**：`build\release.ps1`；**提交前守卫**：`build\check-staged.ps1`。
- **发布状态**：未发布。发布前必须过 `release.ps1` 的三道守卫
  （版本号四段、无调试通道、PE 架构 x86）与 P4 实机验收。
