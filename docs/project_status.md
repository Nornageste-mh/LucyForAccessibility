## 1. 项目概况

- **目标**：让盲人玩家用读屏软件（NVDA / 争渡 / SAPI）全程键盘通关本作，
  且补丁不给游戏新增导航模式或可见界面（Framework 第 0 条纪律）。
- **交互形态**：C 型——原生键盘不覆盖界面、没有控件模型；
  补丁走「拟态原生键盘」（方向键 / Enter → 鼠标移动 + 按下消息），
  不新增模式开关。详见 `docs\交互形态判定.md`。
- **拟态点击的引擎行为**：`Engine.dll` 的 USER32 导入表里没有 `GetCursorPos` /
  `SetCursorPos` / `SendInput`——界面靠 `WM_MOUSEMOVE` 的 lParam 定位置、
  `GetAsyncKeyState` 轮询按钮；补丁 `PostMessage` 合成鼠标消息并让按钮保持按下
  约 **2000ms**（实测不到 1 秒不认、2000ms 成立），因此每次激活约 **2.2 秒**生效，
  期间按键被忽略。点击由 tick 线程排队，不阻塞键盘钩子。
- **注入方式**：替换游戏目录里的 `d3dx9_40.dll`（游戏自带的 DirectX 运行库，
  同目录优先加载）；原文件改名为 `d3dx9_40_orig.dll` 保留。卸载时还原。
- **补丁的日志与配置**：`游戏目录\a11y\`（`a11y.log` / `config.ini`；
  `nvdaControllerClient.dll` 为**可选**，需玩家自行放置，补丁不随包分发）。
- **不碰的东西**：存档在 `游戏目录\Saves\`，设置在 `Config.nkenv`，补丁不直接改写
  这两处（由游戏自己写；卸载**不清除**）。
- **构建入口**：`build\build.cmd`（32 位，`dev` 参数为开发版）；
  **发布**：`build\release.ps1`；**提交前守卫**：`build\check-staged.ps1`。
- **发布状态**：未发布。发布前必须过 `release.ps1` 的三道守卫
  （版本号四段、无调试通道、PE 架构 x86）与实机验收。0.2.5.0 起发布包只含
  4 个玩家文档（安装说明 / 常见问题 / 操作约定 / 交互形态判定），
  `project_status.md` 与 `AUDIT-*.md` 不进包；包内带 `VERSION.txt`
  （版本号 + 构建时间 + DLL SHA256）；旧 zip 与旧 release_stage 自动清理。
